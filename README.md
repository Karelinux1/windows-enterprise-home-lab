
# Windows Enterprise Home Lab

## Overview

This repository documents my hands-on IT home lab projects focused on Windows Server administration, Active Directory, networking, PowerShell automation, and IT support.

The goal of this lab is to develop practical technical skills by building and managing a small enterprise-style Windows environment from the ground up.

Each project includes documentation, configuration steps, PowerShell commands, troubleshooting exercises, and screenshots demonstrating the work performed.

## Technical Skills

The lab will demonstrate practical experience with:

- Windows Server 2022 administration
- Active Directory user and group management
- DNS and DHCP configuration
- Windows 11 domain integration
- Group Policy Objects (GPO)
- File sharing and NTFS permissions
- PowerShell scripting
- Network troubleshooting
- Windows security and administration
- IT documentation and ticket resolution
